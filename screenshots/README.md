# Spin Wheel Lottery — Screenshots

This folder contains screenshots demonstrating the interface and functionality of the Spin Wheel Lottery web application.

## Screenshots Included

* **Lottery Homepage:** Displays the initial page with the Spin button.
* **Lottery Animation:** Shows the spinning animation while the lottery draw is in progress.
* **Lottery Result:** Displays the randomly generated five-digit lottery number and the Spin Again button.

These screenshots demonstrate the application's interactive interface, animation, and random-number generation functionality.
